# Create: Cybernetics (кратко по-русски)

Дополнение для [Create](https://github.com/Creators-of-Create/Create) на **Minecraft 1.21.1 / NeoForge**: кибернетические импланты, программируемые кибердеки и модульная прокачка персонажа.

Импланты **производятся** на линиях Create, **устанавливаются** в кинетическом хирургическом кресле и **программируются** кибердеком (язык Synapse). Тиры I-V усиливают те же самые способности, а не добавляют дубликаты предметов.

## Язык и внутриигровая документация

- Мод переведён на русский (`ru_RU`): предметы, блоки, экраны, сообщения, клавиши и руководство.
- **Полевое руководство** - внутриигровой справочник из 12 глав: первые шаги, тело и нейронная нагрузка, заряд, кресло имплантации, управление, тиры, каталог имплантов, сборка кибердека, первая программа, шпаргалка по Synapse, машины Create, решение проблем.
- Открывается клавишей `H` (переназначается: «Открыть Полевое руководство») или ПКМ по предмету. Новые игроки получают его при первом входе (серверный конфиг `manual.giveOnFirstJoin`). Рецепт: книга + красная пыль.
- Все примеры программ в руководстве проверяются тестом `LangAuditTest`: они обязаны компилироваться.

## Самое короткое введение

1. Гражданские детали (медная проволока, синтетическое волокно, механический сервопривод, гражданский корпус) и Кибернетическое ядро на верстаке - без ядра не работает ничего. Базовые импланты I тира тоже крафтятся на верстаке.
2. Кресло имплантации + Кинетический зарядник + вал с вращением.
3. Биоинтерфейсный гель (миксер: вода + слизь + костная мука + сахар) в бак кресла.
4. ПКМ по креслу: сначала ядро, потом остальные импланты. Следите, чтобы нейронная нагрузка не превышала ёмкость ядра.
5. Зажмите `R`, чтобы пользоваться активными имплантами; `K` открывает кибердек.
6. Грейды II-V - сборочные линии Create с деталями своего тира (сталь, кремний, логические чипы, композит, экспериментальное ядро). На V тире открываются особые умения (слой 5).

Подробности, рецепты и примеры - в игре, в Полевом руководстве. Дизайн-документы и сборка: см. [README.md](README.md).
